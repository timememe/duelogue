# Демо-роадмап v0.1

Порядок и действия до состояния демки. Дата феста (Next Fest окт-2026 vs фев-2027) не
зафиксирована — список от неё не зависит: при более длинном сроке тот же порядок просто
проходится глубже/полнее на каждом шаге, а не расширяется по пунктам. Живой документ,
обновлять по ходу как остальные спеки в `context/`.

Статусы — по ревизии кода на 2026-08-17.

## 1. Сшить забег с настоящим боем — критический путь, первым

Без этого пункта демку не показать целиком: карта забега (`core/run/run_map.gd`) реально
рандомизирует противников по сиду, но сам бой внутри забега сейчас фейковый —
`run_controller.gd`/`resolve_room()` резолвит комнату вручную 4 кнопками win/lose с
придуманным `final_zal`; настоящая боевая сцена не вызывается (комментарий в коде: «Пока
настоящая боевая сцена не подключена»).

- Заменить fake-resolve в `resolve_room()`/`battle_config()` на реальный запуск
  `debate_screen`/`battle_controller` с конфигом энгейджмента (тема × сторона × оппонент ×
  гонорар — уже спроектировано, `context/zal_run_v0.1.md`)
- Прокинуть исход настоящего матча (`final_zal`, outcome) обратно в run-state вместо ручных
  кнопок
- Связать `OPP_POOL`/`BOSS_POOL` (сейчас голые строки имя/стиль/твист) с
  `core/characters/character_core.gd` — иначе «загруженные персонажи как босс» не работает,
  дерутся имена без лиц
- Первый прогон — по §9 спеки: линейный мини-забег на 3 боя + награда-замена, не вся карта
  сразу
- Открытые развилки мета-входов в бой (стартовый крен зала, стартовая доска, разведка) — по
  §10 спеки решает игрок по ходу, не додумывать заранее

дальше базовой колоды.

## 8. Ситуативные карты — решено: делаем, спека `context/situational_cards_v0.1.md`

Не существуют как тип вообще — только 3 меха-типа (Тезис/Разбор/Установка), различаются по
отношению к победе, не по контексту появления. Решение принято 2026-08-19: делаем, не
переносим — но оказалось шире «1–2 карт»: три подсистемы (карты-реакции, эмоц. агентность
«Сорваться», QTE-карты), не одна механика с нуля.

- Спека, лестница внедрения и открытые развилки: `context/situational_cards_v0.1.md`
- Первая связка в работе — эмоц. агентность + карты-реакции; QTE-карты припаркованы на
  отдельный заход (для них «первый кандидат на перенос при нехватке времени» остаётся в силе)
- Всё ещё в силе: без общей системы условий появления — каждый триггер захардкожен на своей
  карте, три подсистемы не унифицируются под один «движок условий» (та же дисциплина, что
  уже применена к статусам)
