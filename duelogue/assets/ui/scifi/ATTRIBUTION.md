# Sci-fi HUD textures

Source: Kenney "UI Pack - Sci-fi" (Kenney Game Assets All-in-1 3.7.0), licence **CC0**.

Composited / renamed for DUELOGUE's battle HUD (meters only):

| file              | built from                                             | use                                   |
|-------------------|-------------------------------------------------------|---------------------------------------|
| `zal_fill.png`    | `barHorizontal_white_{left,mid,right}`                | Зал bar fill, 9-patch, tinted per side |
| `zal_groove.png`  | `barHorizontal_shadow_{left,mid,right}`               | Зал bar recessed track                 |
| `strain_fill.png` | `barVertical_white_{top,mid,bottom}`                  | emotion strain fill, tinted by HP grad |
| `strain_groove.png`| `barVertical_shadow_{top,mid,bottom}`                | emotion strain recessed track          |
| `plate.png`       | `metalPanel.png` (verbatim)                           | dark-modulated frame plate behind bars |
| `frame_glass.png` | `glassPanel.png` (verbatim)                           | optional translucent frame overlay     |

9-patch margins: horizontal files 6px left/right; vertical files 6px top/bottom;
`plate.png` / `frame_glass.png` 8px all sides.
